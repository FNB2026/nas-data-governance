# Support

## Usage Questions and Bugs

Use GitHub Issues for reproducible, sanitized questions and defects. Include the command, application version or commit, operating system, expected behavior, and a minimal reproduction built from synthetic files.

Do not attach a production database, JSONL index, scan log, private diagnostic report, screenshot containing real paths, or any source file from the governed storage.

## Security Issues

Boundary bypasses, unsafe filesystem changes, sensitive-path disclosure, credential exposure, and rollback failures must follow [SECURITY.md](SECURITY.md). Do not report them in a public issue.

## Project Scope

Support covers the current `main` branch and the latest published release. Environment-specific NAS, SMB, filesystem, or permission behavior may require a sanitized local reproduction before it can be investigated safely.
