# ADR-0001：首个里程碑只读

状态：已超越（M1 只读基座已扩展为 M3 安全执行 + M6 生产化收束；保留作为历史决策记录）

## 决策

第一个可运行版本只允许读取元数据和文件内容以生成索引，不提供移动、重命名、删除、覆盖、硬链接或隔离操作。

## 原因

白皮书要求扫描、分析、计划和执行分离。只读闭环可先验证大规模扫描、分层哈希、索引与完全重复识别，同时不会把尚未成熟的目录语境判断转化为破坏性动作。

## 后果

CLI 仅有 `scan` 与 `duplicates`。执行层的数据结构可以提前定义，但不会接入 CLI，直到隔离、stale 检查、审计和回滚测试同时具备。
