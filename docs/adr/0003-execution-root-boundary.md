# ADR-0003：执行器必须绑定显式源根目录

状态：已接受

## 决策

`executor.QuarantineConfig` 必须提供一个或多个绝对 `SourceRoots`。写入动作的源路径必须位于其中之一；根目录以下的任意符号链接均拒绝执行。隔离目标也会在隔离根目录内进行同样的相对路径检查。

## 原因

计划文件可能被篡改、复用或误用于错误任务根。只检查文件本身是否是符号链接不足以阻止 `/任务根/链接/文件` 这种祖先链接穿越。白皮书和工程守则均要求不越过任务根目录且不跟随危险符号链接。

## 后果

执行 API 需要明确来源范围，不能使用隐式“任意绝对路径”。macOS 等平台的系统级路径别名可以存在于任务根之外；检查只从已批准根目录向下开始，避免把系统别名误判为用户数据路径中的链接。
