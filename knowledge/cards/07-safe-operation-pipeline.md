# 安全操作流水线

固定流程：扫描 → 分析 → 生成计划 → 用户审阅 → 执行前复核 → 执行 → 校验 → 审计。

默认删除应替换为隔离。执行前复核路径、大小、mtime、inode、哈希和目标状态；变化则标记 STALE 并停止。跨卷移动必须按“复制—校验—删除源”执行，复制成功不代表移动成功。

每个写动作在执行前后向 `execution_journal` 表落盘一条记录（pending→done/failed→rolled_back），进程崩溃后 `recover` 可扫描未完成的动作并回滚或重置计划，保证源路径与目标路径的一致性。回滚失败的动作进入人工复核，不自动重放。审计日志不记录路径或内容，仅记录字节数、stale 原因与错误类型。
