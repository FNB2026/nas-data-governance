网站隐私说明

版本日期：2026-11-19

本说明仅适用于 NDG 官方网站（ndg.fnbapp.net），不替代桌面应用、Docker 预览或第三方服务的独立隐私与安全文档。

网站数据处理

当前网站为静态信息展示，不设用户登录、注册、表单提交、广告跟踪、站内行为分析、第三方分析脚本或主动设置的追踪 Cookie。访问网站时，托管及网络服务方 Cloudflare 可能基于安全与运营需要处理基础请求数据（如 IP 地址、请求时间与访问记录）。

外部链接与资源

网站提供 GitHub Releases 和项目文档链接，并从 GitHub 公共仓库加载演示截图。访问这些资源时，相关第三方可能处理必要的网络请求信息，请参阅其隐私政策。

桌面应用数据

NDG 应用遵循本地优先的产品原则；具体数据处理、安全边界和权限请以所下载版本的文档为准。网站不会接收用户在 NDG 中扫描的文件内容。

更新与联系

网站说明可能随功能更新而调整。安全漏洞请通过 项目安全政策 提供的渠道反馈，一般问题请访问 GitHub Issues，不要公开提交私密材料。
